# Andrew Hughes — launch-ready website

Static, responsive single-page website. Open `index.html` to preview.

## Publish to GitHub Pages

1. In GitHub, use the **public** repository `andrewhhughes09/hiimandrew`.
2. Upload the **contents** of this directory (not the enclosing folder) to the root of the repository. Commit to `main`.
3. Open Settings → Pages, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. When deployment completes, visit `https://andrewhhughes09.github.io/hiimandrew/`.

The GitHub repository will be public because GitHub Pages uses a public repository on GitHub Free. The public site does not automatically display a link to the GitHub account. A custom domain can be added later in Pages settings.

Files: `index.html`, `styles.css`, `script.js`, `assets/` (including the static professional introduction PDF).

Contact links and the PDF download are configured. No analytics or cookies are included.
